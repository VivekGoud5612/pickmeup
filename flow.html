01
Environment Core
Gymnasium · 20×20 grid · GameState
Built

Static agent data (HP, stamina, defense, ranges) pre-loaded once. Runtime state — positions, cooldowns, status effects — lives in mutable NumPy arrays.

  • Local obs (4, 24) → Actor input
  • Global state (4, 96) → Critic input
  • Role embeddings (4, 4) one-hot: Tank / Dealer / Healer / Boss
  • Action space — MultiDiscrete(8): movement (0–3) + role skills (4–7)
  • Action & active masks block invalid / dead-agent actions at the source
02
Reward Pipeline
Phase-annealed potentials
Built

Handcrafted potentials (HP score, formation, tactical position) dominate early training. An annealing alpha — scaled by global_step / TOTAL_STEPS — smoothly hands control to raw combat/terminal rewards as training matures.

  • Phase weights: 0 → 0.2 → 0.5 → 1.0 (value-based)
  • Terminal rewards: win bounty, death penalty
  • Computed from old-state vs new-state, no summary dict
03
Parallel Execution
SharedSubprocessVectorEnv · 8 workers
Built

Python's GIL blocks true thread parallelism, so each environment runs as an isolated OS process. Instead of pickling NumPy arrays through Pipes, workers write directly into POSIX shared memory — the main process reads it with zero copy, zero serialization.

04
Curriculum Engine
Dynamic difficulty scaling
Active

A rolling deque of the last 50 outcomes tracks hero win-rate. Crossing 85% triggers a level-up: checkpoint saved, queue cleared, new level broadcast down every Pipe.

  • Boss max_hp scales up, capped at 1000
  • Hero spawn radius pushes outward with level
  • Currently step-gated: boss HP intentionally reduced early to validate learning signal first
05
Rollout Buffer + GAE
Batched temporal tensor store
Built

Pointer-based insertion into pre-allocated float32 arrays — [steps, envs, agents]. Death masking gives dead agents log-prob 0 rather than removing them, keeping tensor shapes fixed.

  • GAE computed backward: δ + γλ·gae(t+1), vectorized as an env-agent matrix
  • next_non_terminal zeroes the bootstrap at episode boundaries
  • Truncated games store a terminal observation separately — prevents bootstrapping into garbage values from the next episode
06
MAPPO Update Loop
Actor / Critic · orthogonal init · LayerNorm
Active debugging

Shared-weight actor with role embeddings (DOTA2-style parameter sharing). Value normalizer tracks running mean/std so critic targets stay on a stable scale. Huber loss on the critic, PPO-clip + entropy bonus on the actor, gradients clipped at norm 10.

  • Entropy coefficient now decays with curriculum alpha — earlier fixed-coefficient bug caused flat 1.2–1.5 entropy
  • Fixed: team_mask uninitialized → both sides "dead" → instant reset loop
  • Fixed: global state not written on worker reset → critic evaluating stale state
⚠ Open question — zero-sum gradient collision

Hero and Boss currently share one network. In a zero-sum game, a winning Hero move and the corresponding Boss loss backprop opposite-signed gradients through the same hidden layers in the same batch — they cancel. Diagnosed via entropy collapse (~1.3) and advantage flatlining at 0.0. Planned fix: split into separate hero_agent / boss_agent networks, sliced from the same rollout buffer by agent index.

07
Checkpoint
.pt — milestone snapshot
Built

Saved on every curriculum level-up. This is the single artifact that bridges training and inference — everything below this line loads from here, nothing upstream needs to know inference exists.

08
Inference Engine
FastAPI · Ghost Engine · /ws/combat
Designed — build next

A second, gradient-free instance of the same Env loads the best checkpoint and runs in pure inference mode. A WebSocket endpoint drives a continuous game loop — query network, step physics, serialize state.

  • Uvicorn serving a single /ws/combat WebSocket route
  • Payload: positions, HP, step count — kept deliberately lightweight
  • Target tick rate: 30+ fps streamed to any connected client
09
Visualizer Frontend
React + HTML5 Canvas
Designed — build next

React handles connection lifecycle only. Incoming JSON writes into a useRef — deliberately not useState — so the DOM never re-renders 30 times a second.

  • A pure requestAnimationFrame loop runs at 60fps, fully decoupled from React's render cycle
  • Reads the ref's live memory address each frame, redraws grid + heroes + boss with 2D canvas math
  • This split is what avoids the React reconciliation cliff under a 30fps data stream
